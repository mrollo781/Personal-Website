# Personal Portfolio Website

A responsive personal portfolio website designed to showcase my academic background in Computer Science at Queen's University Belfast, alongside my professional experience and software development projects.

**Live Site:** [mrollo781.github.io/Personal-Website](https://mrollo781.github.io/Personal-Website/#about)

## Features
* **Education & Experience:** Outlines my academic progression and professional roles.
* **Technical Skills:** Highlights my proficiency in current programming languages, tools, and methodologies.
* **Projects Showcase:** Serves as a central directory for my software engineering projects and GitHub repositories.
* **Responsive Design:** Built with custom CSS to ensure a seamless viewing experience across desktop and mobile devices.

## Technologies Used
* **HTML5:** Semantic page structure and content formatting.
* **CSS3:** Custom styling, layout management, and mobile responsiveness.
* **GitHub Pages:** Live hosting and deployment directly from the repository.

## Local Setup
To run or modify this project on your local machine:
1. Clone the repository: `git clone https://github.com/mrollo781/Personal-Website.git`
2. Open the project folder in your preferred code editor.
3. Open `index.html` in any web browser.
